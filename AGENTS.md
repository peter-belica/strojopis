# Projektové pravidlá

- Pri vysvetľovaní stručne uveď princíp, logiku a význam použitých skratiek.
- Knižnice, fonty a ďalšie externé podklady musia mať overenú bezplatnú licenciu umožňujúcu komerčné použitie. Nestačí dostupnosť na stiahnutie zdarma.
- Zachovaj povinné licencie a autorské oznámenia. Pri pridanej závislosti zaznamenaj verziu, zdroj a licenciu; pri priamom prevzatí kódu aj konkrétny commit a kontrolný súčet.
- Kontrola `npm run validate:licenses` musí prejsť. Neznámu licenciu over pred použitím; nemeň zoznam povolených licencií len na obídenie kontroly.
